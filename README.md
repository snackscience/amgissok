# 암기쏙 (SchoolKit)

형광펜이나 (괄호)로 표시한 곳을 가려 주는 암기장 앱입니다.

## 올리는 방법 (GitHub Pages)
1. GitHub에 `amgissok` 저장소를 만듭니다.
2. 이 폴더의 파일을 **폴더 구조 그대로** 모두 올립니다.
   - index.html, privacy.html, manifest.webmanifest, sw.js, icons 폴더
3. Settings → Pages → Branch를 `main`, `/ (root)`로 저장합니다.
4. 잠시 뒤 `https://snackscience.github.io/amgissok/` 에서 열립니다.

## 폰에 설치하기
- 안드로이드(크롬, 삼성 인터넷): 위 주소 접속 → 오른쪽 위 **앱 설치** 버튼 → 설치
- 아이폰(사파리): 위 주소 접속 → **앱 설치** 버튼을 누르면 나오는 안내대로 공유 → 홈 화면에 추가

## 앱을 고친 뒤에는
`sw.js` 맨 위 `VERSION` 숫자를 올려 주세요(예: v1.1.0 → v1.1.1).
그래야 이미 설치한 학생 폰에도 새 버전이 적용됩니다.
